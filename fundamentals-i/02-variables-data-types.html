Module 02

Variables and Data Types

Store numbers, text, and true-or-false values, then convert them and read input from the user.

Names for Values

A variable is a name you choose. A constant is a name you treat as fixed, written in uppercase.

  • student_name changes as the program runs
  • MAX_SCORE stays the top mark
  • The type tells Python what operations are allowed
Types

Numbers, Text, and Booleans

int is a whole number, float is a decimal, str is text, and bool is True or False.



type() reports the kind of value a name currently holds.




Conversion
Changing One Type into Another


input() always returns text. Convert it before you do arithmetic.






int(), float(), and str() are the conversions you will use most often.
