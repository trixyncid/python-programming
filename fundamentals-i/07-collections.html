Python Collections

Store groups of values in lists, tuples, dictionaries, and sets, then visit every item.

Many Values, One Name

Lists and tuples keep order. Dictionaries answer a lookup. Sets remember whether a value is present.

  • A list can grow and shrink
  • A tuple stays in the order you wrote
  • Keys in a dictionary are unique
Lists and Tuples

Order You Can Change, Order You Keep

Index 0 is the first item. A tuple uses parentheses and does not support item assignment.



Use a list while the group is still changing. Use a tuple for a fixed pair or record.




Dictionaries and Sets
Look Up by Key, Keep Values Unique


A dictionary maps a key to a value. A set stores each value once.






A repeated name in a set is stored once. Membership tests use in.
