The art of giving instructions to machines
What is Programming?

Talking to Computers

Programming is the process of creating a set of instructions (code) that tells a computer what to do.

Think of it like writing a recipe — you must be precise, step by step.

  • Computers only understand binary (0s and 1s)
  • Programming languages translate human ideas into machine instructions
  • Python reads like English, making it beginner-friendly
Computational Thinking

The Four Pillars

# 1. DECOMPOSITION — Break a big problem into smaller parts
#    Example: Building a website
#    - Design the layout
#    - Write the HTML structure
#    - Add CSS styling
#    - Create JavaScript interactivity

# 2. PATTERN RECOGNITION — Find similarities
#    Example: Grading 100 exams = same steps, different data

# 3. ABSTRACTION — Focus on what matters, ignore details
#    Example: Using print() without knowing HOW it works internally

# 4. ALGORITHM DESIGN — Step-by-step solution
#    Algorithm to make coffee:
#    1. Fill kettle with water
#    2. Boil water
#    3. Add coffee grounds to filter
#    4. Pour hot water over grounds
#    5. Wait 3 minutes
#    6. Serve
Tip: Before writing any code, try to solve the problem on paper first. Break it into steps. That is your algorithm.
Your First Program

Hello, World!

# Save this as hello.py and run: python hello.py

# print() displays text on the screen
print("Hello, World!")

# You can print anything:
print("Welcome to Python Programming!")
print("I am learning to code.")
print("This is exciting!")

# Output:
# Hello, World!
# Welcome to Python Programming!
# I am learning to code.
# This is exciting!
Congratulations! You just wrote your first program. The print() function displays text on screen. Every program starts with small steps like this.
Syntax Basics

Python Syntax Rules

# 1. Comments start with #
# The computer ignores everything after #

# 2. Python uses indentation (spaces) for structure
if "yes":
    print("Great!")   # This is inside the if
    print("Let's go!") # Also inside
print("Done")          # This is outside (not indented)

# 3. Python is case-sensitive
name = "Alice"
Name = "Bob"    # This is a DIFFERENT variable!

# 4. No semicolons needed (unlike Java/C++)
print("Python is clean!")

# 5. Line-by-line execution
print("Line 1")   # Runs first
print("Line 2")   # Runs second
print("Line 3")   # Runs third
