Why Decisions Matter

Programs Must Think

Without conditions, every program would do the same thing every time. Decisions make programs flexible and powerful.

  • Weather apps decide: umbrella or sunglasses?
  • Banking systems decide: approve or decline?
  • Games decide: win, lose, or continue?
  • Social media decides: show or hide content?

Every real-world application uses conditions extensively.

if / elif / else

Basic Conditional Structure

# Simple if statement
temperature = 32

if temperature > 30:
    print("It's hot outside!")

# if-else
age = 16

if age >= 18:
    print("You can vote!")
else:
    print("Too young to vote.")

# if-elif-else (multiple conditions)
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print("Grade: " + grade)  # Grade: B
Remember: Use colons (:) after each condition, and indent the code block. Python checks conditions top to bottom and runs the first True branch.
Nested Conditions & Ternary

Advanced Conditionals

# NESTED CONDITIONS -- decisions within decisions
age = 25
has_license = True

if age >= 18:
    if has_license:
        print("You can drive!")
    else:
        print("Get a license first.")
else:
    print("Too young to drive.")

# TERNARY OPERATOR -- one-line if-else
age = 20
status = "adult" if age >= 18 else "minor"
print(status)  # adult

# TRUTHY AND FALSY VALUES
# Falsy: False, 0, 0.0, empty string, [], (), None
# Truthy: True, non-zero, non-empty strings, non-empty lists

name = ""
if name:
    print("Hello, " + name)
else:
    print("No name provided.")  # This runs!

items = []
if items:
    print("We have items")
else:
    print("List is empty.")    # This runs!
