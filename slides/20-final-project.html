Project Requirements

Build a complete Python application that demonstrates everything learned in this course.

  • Use OOP (classes, inheritance, polymorphism)
  • Handle errors gracefully with try/except
  • Read/write files (CSV, JSON, or both)
  • Use at least one external library or API
  • Include comprehensive docstrings
  • Write clean, readable, well-structured code
