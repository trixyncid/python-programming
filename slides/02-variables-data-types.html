Variables are like labeled boxes that hold information
Variables

Named Storage Containers

A variable is a name that refers to a value stored in memory. Think of it as a labeled box where you put data.

  • Variables have a name and a value
  • You create them with the assignment operator =
  • Python figures out the type automatically
  • You can change a variable's value at any time
  • Naming rules: letters, digits, underscores; cannot start with a digit
Data Types

The Five Core Types

# INTEGER (int) — whole numbers
age = 25
students = 150
temperature = -3
print(type(age))   # <class 'int'>

# FLOAT — decimal numbers
gpa = 3.85
pi = 3.14159
print(type(gpa))   # <class 'float'>

# STRING (str) — text in quotes
name = "Alice"
message = 'Hello, World!'
print(type(name))  # <class 'str'>

# BOOLEAN (bool) — True or False
is_student = True
has_graduated = False
print(type(is_student))  # <class 'bool'>

# NONE — absence of value
result = None
print(result)       # None
Type Conversion & Input

Converting and Collecting Data

# TYPE CONVERSION (casting)
num_str = "42"            # This is a string!
num_int = int(num_str)    # Convert to integer: 42
num_float = float(num_str) # Convert to float: 42.0

age = 25
age_str = str(age)        # Convert to string: "25"

price = 19.99
price_int = int(price)    # Truncates: 19 (no rounding!)

# USER INPUT
name = input("What is your name? ")
print("Hello, " + name + "!")

# input() ALWAYS returns a string
age = input("How old are you? ")
print(type(age))  # <class 'str'> -- even if you type 25!

# Must convert explicitly:
age = int(input("Enter age: "))
print("You will be", age + 1, "next year.")
Important: input() always returns a string. Use int() or float() to convert numeric input before doing math.
Naming Rules

How to Name Variables

# VALID variable names:
name = "Alice"
student_name = "Bob"
_private = 42
maxScore = 100      # camelCase (not typical in Python)
MAX_SCORE = 100     # UPPER_CASE for constants
count2 = 5          # digits allowed (not at start)

# INVALID variable names:
# 2name = "Error"     — cannot start with digit
# my-name = "Error"   — no hyphens
# class = "Error"     — "class" is a keyword
# my name = "Error"   — no spaces

# Python convention (PEP 8):
# - Use snake_case for variables and functions
# - Use PascalCase for classes
# - Use UPPER_CASE for constants
first_name = "Alice"    # snake_case
MAX_RETRY = 3          # UPPER_CASE constant

# Good practice: use descriptive names
x = 25          # Bad: what is x?
student_age = 25  # Good: clear meaning
