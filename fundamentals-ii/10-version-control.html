Module 10

Version Control

Track a project with Git: a local repository, commits, branches, merges, and a shared copy on GitHub.

Repository and Commits

Start a History and Save a Snapshot

These commands run in the project folder. Each commit message says why the snapshot exists.

Terminal — copy these commands and run them on your computer.



git status shows what will be included. git add chooses the files. git commit saves them.




Branches and Merges
Work Apart, Then Combine


A branch lets you try a change without rewriting the commits already on main.


Terminal — copy these commands and run them on your computer.





merge brings the feature commits onto the branch you have checked out.




GitHub
A Shared Copy of the Repository


origin is the usual name for the GitHub repository. push sends commits. pull brings in commits from someone else.


Terminal — copy these commands and run them on your computer.





On a shared project, pull before you start work so you are building on the latest commits.
